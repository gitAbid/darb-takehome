# Test Inventory — Business Rule → Test

Every business rule keeps **at least one** test; duplicates and library-behaviour tests are not kept. Paths are
relative to `__tests__/`; titles are quoted as written (an `it.each` row is named by its row label).

Layers: `unit/` = business logic (pure), `integration/` = database, file system, real libraries, `e2e/` = HTTP route →
pipeline → database. Check the mix with `npm run test:mix` (target 50 / 30 / 20).
